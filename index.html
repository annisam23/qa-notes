⚙️ Setup Firebase dulu (± 3 menit)

Config Firebase belum diisi. Ikuti langkah ini sekali saja, lalu deploy ulang file HTML-nya:

  1. Buka console.firebase.google.com → Add project (boleh skip Google Analytics) → tunggu sampai selesai dibuat.
  2. Di menu kiri: Build → Firestore Database → Create database → pilih lokasi server (misal asia-southeast2) → mode Start in test mode → Enable.
  3. Di menu kiri: klik ikon ⚙️ (Project settings) → tab General → scroll ke "Your apps" → klik ikon </> (Web) → beri nama app (bebas) → Register app.
  4. Firebase akan menampilkan object firebaseConfig — copy semua isinya.
  5. Buka file HTML ini di editor teks, cari komentar GANTI_DENGAN_API_KEY di paling atas, dan tempel nilai dari config yang kamu copy.
  6. Simpan file, lalu deploy/upload ulang ke hosting kamu. Selesai — semua orang yang buka halaman ini akan berbagi data yang sama.

Catatan: "test mode" bikin Firestore bisa dibaca/ditulis siapa saja yang tahu config-nya selama 30 hari (lalu terkunci otomatis). Cukup aman untuk tools internal tim jangka pendek — tapi kalau mau dipakai lebih lama, atur Firestore Rules jadi lebih ketat (bisa saya bantu kalau perlu).
